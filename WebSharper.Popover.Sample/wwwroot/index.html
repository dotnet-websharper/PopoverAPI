Popover API Demo

Show and hide native popovers with the Popover API. Popovers are top-layer elements that render above the rest of the page.

Controls

Use showPopover() and hidePopover() to control the popover.

This is a controlled popover!

How it works

  • showPopover() — show the popover in the top layer.
  • hidePopover() — hide the popover.
  • togglePopover() — flip the popover's state.
